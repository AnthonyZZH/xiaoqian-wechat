# 数据与隐私

仓库仅包含通用源代码、合成测试、示例和文档，不包含个人运行数据。

## 运行时数据

`data/` 由本地运行时生成，其中可能包含：

- 允许聊天列表、指定联系人、机器人昵称、模型选择和本机路径。
- 对话上下文、模型整理的记忆、人物印象和群内说法。
- 头像指纹和昵称对应关系。
- 表情原图、界面截图、媒体描述及待审核列表。
- 收发事件、模型调用元数据、搜索词和校准报告。

这些内容都被 `.gitignore` 排除。旧版本的根目录配置、日志、历史文件、备份和本机快捷方式同样不应提交。忽略规则不能阻止 `git add -f`，上传前仍应检查 `git diff --cached` 和文件清单。

## 数据流向

- 模型请求发往配置的 API 地址。默认使用本机回环地址；如果改为远程服务，发送给模型的消息、图片与记忆会离开电脑。
- 启用搜索时，查询词会发送给 DuckDuckGo 或 Bing。可以在“节奏”页关闭搜索。
- 消息与表情通过微信界面发送给指定聊天。
- LM Studio 自身的日志和数据保存行为由该应用管理。

## 记忆

自动整理会过滤部分隐私和指令性内容，但过滤器不能保证覆盖所有情形。记忆仍可能包含个人信息或错误推断，应定期在控制台检查、修改或清空。

手动编辑前的备份保存在 `data/memory/backups/`；清空当前记忆不等于删除历史备份。聊天记录、日志和表情目录也需要按自己的保留习惯分别管理。

## 本次仓库整理

发布目录从明确列出的源文件生成，没有复制原运行目录的 `data/`、`vendor/`、备份、截图、聊天记录、记忆和配置。测试中的个人昵称与群名已替换为合成示例，提交作者使用仓库维护者确认的 Git 身份。
